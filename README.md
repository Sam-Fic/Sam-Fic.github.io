# Sam-Fic Homepage

个人作品集网站，展示开源项目、技术栈与项目经历。

## 设计风格

**视觉风格**
- 主色调：橙色（`#FF6600`），嫣汐的应援色 :)
- 字体：使用 MiSans 字体（站内字体文件），搭配系统字体栈
- 风格：简洁现代，纯直角设计

**交互动效**
- 导航链接下划线动画：从右向左滑入的 clip-path 效果
- 按钮悬停：填充色从左向右滑入的过渡效果
- 卡片悬停：微妙的视觉反馈
- 页面滚动：顶部进度条实时反馈浏览进度

## 核心特性

### 国际化（i18n）
- 支持中文（默认）与英文两种语言
- 页面右上角一键切换语言
- 所有正文内容、按钮文字均实现双语覆盖

### 主题切换
- 支持亮色/暗色主题切换
- 切换状态通过 CSS 变量系统实现无缝过渡
- 主题偏好保存在本地 localStorage，刷新后保持

### 响应式设计
- 移动端适配：汉堡菜单侧边导航
- 灵活的卡片布局与网格系统
- 触摸友好的交互区域

### 浏览反馈
- 滚动进度条：页面顶部橙色进度条实时显示阅读进度
- 平滑滚动：锚点导航使用平滑滚动跳转
- 返回顶部按钮：滚动一定距离后出现

## 技术实现

**前端技术栈**
- HTML5 + CSS3 + Vanilla JavaScript
- CSS 自定义属性（CSS Variables）实现主题系统
- 无框架依赖，轻量高效

**字体与图标**
- 中文字体：MiSans（站内自托管）
- 图标库：Material Icons + Font Awesome 6

**目录结构**
```
my_homepage/

```
