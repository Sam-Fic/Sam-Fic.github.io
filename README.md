# Sam-Fic Homepage

个人作品集网站，展示开源项目、技术栈与项目经历。

## 设计风格

**视觉风格**
- 主色调：橙色（`#FF6600`），嫣汐的应援色 :)
- 字体：使用 MiSans 字体（站内字体文件），搭配系统字体栈
- 风格：简洁现代，纯直角设计

**交互动效**
- 导航下划线：从右向左滑入的 clip-path 效果，并随滚动高亮当前章节
- 按钮悬停：填充色从左向右滑入
- 卡片悬停：微妙的视觉反馈
- 页面滚动：顶部进度条实时反馈浏览进度
- 滚动入场：区块与卡片滚入视口时依次浮现
- 主题切换：色块自上而下直线擦过全屏，盖满屏幕的瞬间完成切换
- 图片预览：缩略图 → 全屏的 FLIP 连贯过渡，支持滚轮 / 双指缩放与拖拽

## 核心特性

### 国际化（i18n）
- 支持中文（默认）与英文两种语言，页面右上角一键切换
- 所有正文内容、按钮文字均实现双语覆盖

### 主题切换
- 支持亮色 / 暗色主题切换
- 切换状态通过 CSS 变量系统驱动
- 偏好保存在 localStorage；未手动选择时跟随系统 `prefers-color-scheme`

### 响应式设计
- 移动端适配：汉堡菜单侧边导航
- 灵活的卡片布局与网格系统
- 触摸友好的交互区域

### 浏览反馈
- 滚动进度条：页面顶部橙色进度条实时显示阅读进度
- 平滑滚动：锚点导航使用平滑滚动跳转
- 返回顶部按钮：滚动一定距离后出现

### 无障碍与性能
- 尊重系统 `prefers-reduced-motion`，开启后关闭全部动效
- 图片预览具备焦点管理：打开时移入焦点并锁定 Tab，关闭后归还焦点
- 控件边框与装饰分隔线使用两套变量，保证控件轮廓的可见性
- 图标全部内联自托管，无任何外部 CDN 依赖（国内可正常显示）
- 滚动相关逻辑合并进同一帧，进度条与返回顶部共用一次布局读取

## 技术实现

**前端技术栈**
- HTML5 + CSS3 + Vanilla JavaScript
- CSS 自定义属性（CSS Variables）实现主题系统
- 无框架依赖，轻量高效

**字体与图标**
- 中文字体：MiSans（站内自托管）
- 图标：全部内联 SVG sprite（`index.html` 顶部），含 GitHub / Gitee / Bilibili 品牌图标

**目录结构**
```
my_homepage/
├── index.html          # 主页面（内联 SVG 图标 sprite + 防闪烁脚本）
├── README.md           # 项目说明
├── .gitignore
└── assets/
    ├── css/
    │   └── style.css   # 样式表
    ├── fonts/
    │   └── MiSans-Demibold.ttf   # 站内自托管中文字体
    ├── images/         # 头像、项目与经历配图
    └── js/
        └── main.js     # 交互逻辑（语言/主题、菜单、复制、进度条、
                        #           滚动入场、导航高亮、图片预览）
```
